# WPA Analyze Agent

This package provides a WPR trace analysis entry agent for SQL Server.

Included content:

- `wpr-trace-analysis.agent.md` — routing agent for WPR/ETL investigations
- `wpr-trace-analysis-readme.txt` — setup and WPA MCP prerequisites
- `wpr-cpu-analysis/SKILL.md` — CPU hotspot investigation
- `wpr-cpu-comparison/SKILL.md` — baseline vs problem trace comparison
- `wpr-io-analysis/SKILL.md` — disk/file I/O investigation

Use this package when investigating SQL Server ETL traces in WPA and you need
guided analysis for CPU or I/O issues.
